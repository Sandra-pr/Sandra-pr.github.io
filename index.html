Introduktion

Så fungerar Claude Code

Claude Code är en AI-assistent som kan läsa, skriva och ändra filer på din dator. Du beskriver vad du vill ha med vanliga ord, så gör Claude jobbet och visar vad som har ändrats.

Vad är Claude Code?

Vanliga AI-chattar svarar med text som du själv måste kopiera och klistra in. Claude Code arbetar i stället direkt i dina projekt: det kan öppna filer, skapa nya, köra kommandon och testa att resultatet fungerar.

Det finns i terminalen, som en app för Mac och Windows, på webben och i kodredigerare som VS Code.

Så går ett uppdrag till

  1. Du berättar vad du villTill exempel: ”Gör en enkel hemsida om mitt företag.”
  2. Claude tittar sig omkringDet läser de filer som redan finns för att förstå sammanhanget.
  3. Claude gör en plan och utför denFiler skapas eller ändras, och kommandon körs vid behov.
  4. Du godkänner viktiga stegInnan något känsligt görs, som att publicera eller radera, frågar Claude först.
  5. Du granskar resultatetDu ser exakt vad som ändrats och kan be om justeringar.

Vad kan man använda det till?

Bygga saker

Hemsidor, små appar, skript och verktyg, även om du inte kan programmera själv.

Laga fel

Klistra in ett felmeddelande så letar Claude upp orsaken och rättar den.

Förstå kod

Fråga vad en fil gör, så får du en förklaring på vanlig svenska.

Sköta rutinjobb

Byta namn på filer, uppdatera texter eller publicera på GitHub.

Att komma igång

Om du använder terminalen startar du Claude Code i den mapp du vill arbeta i:

cd mitt-projekt
claude

Sedan skriver du helt enkelt vad du vill ha gjort.

Tips: Var konkret. ”Lägg till en kontaktsida med min e-post och en karta” ger bättre resultat än ”gör sidan bättre”.
